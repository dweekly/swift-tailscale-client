## 3. Focused remediation — 2026-09-18

These are local working-tree results, not exact-SHA release qualification.

- **Streaming EOF:** Unix streaming now throws `malformedResponse` when EOF
  interrupts a chunk body, omits the terminal zero chunk, or interrupts trailers.
  Real-socket regressions cover all three cases and preserve successful chunked
  and EOF-delimited final-line handling.
- **Slow consumer:** the regression sends 1,024 lines totaling over 1 MiB,
  deliberately stalls consumption, and requires the entire ordered result.
  The fault server now handles partial writes and suppresses SIGPIPE.
- **Release evidence:** CI produces JSON reports and matching logs. Release
  aggregation requires each unit/sanitizer lane and both integration suites on
  each supported daemon track, with matching source SHA and explained skips.
  Downloads are outside the checkout. The API-freeze job now checks fresh 1.0
  symbol graphs, and missing API/conformance evidence is no longer hardcoded as
  passed. GitHub execution of this revised workflow remains pending.
- **Soak verdicts:** missing RSS/descriptor probes remain null and fail the
  run; insufficient samples cannot pass a plateau check. Negative tests now
  call the actual runner. Internal queue, baseline-recovery, cache-integrity,
  and tight-loop metrics remain unmeasured rather than invented.

Local validation: 876 Swift tests executed with zero failures; 45 live-daemon
integration tests intentionally skipped. The release tooling has 42 rehearsal
checks, 10 report-contract tests, and 8 soak tests. Fresh API validation preserved
981 public symbols and 1,307 relationships. A 30-second synthetic fault soak
processed 5,271 notifications, measured peak RSS of 15,072 KiB, and ended with
zero net file/socket descriptor growth. This short run does not satisfy the
multi-day soak gate or establish live daemon conformance.

## 5. Apple-only release qualification — 2026-09-19

At the maintainer's direction, required CI now builds and tests Swift on Apple
platforms only: macOS unit tests/Thread Sanitizer/DocC/API verification and
iOS/tvOS/watchOS builds. Linux builds, the Linux daemon matrix, and Linux binary
publication are deferred. The older matrix descriptions above are historical
implementation records, not current support claims. The Linux integration
workflow is manual-only. The first PR CI run exposed a Linux compile failure;
that platform remains explicitly unqualified instead of blocking this release.
