## 2. Gate-by-Gate Evidence Breakdown

### Gate G1: Safe Writes
- **Invariants**: Lossless recursive preservation of unmodeled fields in `ServeConfig` (root, TCP, Web, Services, Handlers); 64-bit integer precision without floating-point rounding; mandatory ETag conditional updates (`setServeConfig(_:matching:)`, `updateServeConfig`); explicit unconditional replacement (`replaceServeConfigUnconditionally`); `MaskedPrefs` selective property serialization (`<Property>Set = true`).
- **Commits**: `5e6ddc7` (PR 02: lossless ServeConfig and 64-bit integer precision), `bbbe54a` (PR 03: conditional snapshot concurrency).
- **Test Evidence**:
  - `Tests/TailscaleClientTests/ReadinessRegressionTests.swift:26` (`testServeConfigPreservesUnknownRootAndNestedFields`)
  - `Tests/TailscaleClientTests/ServeConfigLosslessTests.swift` (10 tests covering arbitrary JSON value hierarchies)
  - `Tests/TailscaleClientTests/ServeAPITests.swift` (12 tests covering ETag optimistic concurrency)
  - `Tests/TailscaleClientTests/ConsumerValidation/FleetAgentConfigurationTests.swift:202` (`testLosslessUnmodeledFieldPreservation`)
- **Observed Metrics**: 100% round-trip JSON key preservation; 0 precision loss on `UInt64.max` (`18446744073709551615`); HTTP 412 Precondition Failed handled cleanly.

### Gate G2: Transport Hardening & Resource Ownership
- **Invariants**: Unconditional 64 KiB head limit in `HTTPHeadBuffer.feed` (even with `\r\n\r\n` present); unary response payload length matches `Content-Length` exactly; chunked transfer decoding enforces `ChunkedTransferDecoder.isComplete`; socket I/O cooperative non-blocking (`select`/`poll` $\le 500\text{ms}$) checking `Task.isCancelled`, terminating within $\le 1\text{s}$; RAII single-ownership socket cleanup.
- **Commits**: `3be767b` (PR 04: head limits and framing), `f7ead04` (PR 05: socket cancellation and descriptor ownership).
- **Test Evidence**:
  - `Tests/TailscaleClientTests/ReadinessRegressionTests.swift:105` (`testHTTPHeadExceeding64KiBFailsWithTypedMalformedResponseEvenWithDelimiter`)
  - `Tests/TailscaleClientTests/ReadinessRegressionTests.swift:145` (`testChunkedTransferUnaryRequiresCompletion`)
  - `Tests/TailscaleClientTests/ReadinessRegressionTests.swift:175` (`testContentLengthFramingEnforcedInUnaryResponse`)
  - `Tests/TailscaleClientTests/UnixSocketFaultTests.swift` (15 tests exercising `FaultUnixServer`)
  - `Tests/TailscaleClientTests/TransportCancellationChallengerTests.swift` (150-cycle kernel descriptor introspection test)
- **Observed Metrics**: Zero file descriptor leaks across 100+ connect/cancel/failure iterations; cancellation responsiveness $\le 500\text{ms}$; clean Linux ThreadSanitizer execution.

### Gate G3: Bounded Observable Streaming & Recovery
- **Invariants**: `StreamingResponse` validates HTTP status code (200 OK), headers, and `Tailscale-Version` before yielding body stream lines; `IPNBusEvent` cleanly segregates data notifications (`.notification(IPNNotify)`) from connection lifecycle states (`.lifecycle(IPNBusLifecycle)`); bounded queues enforce 256 events or 16 MB ceiling, yielding `.stateGap(reason: "buffer_overflow")` or throwing `streamOverflow`; classified retry with capped exponential backoff and jitter; permanent 401/403 authorization failures terminate immediately; deterministic producer task cancellation.
- **Commits**: `be6bb42` (PR 06: streaming response metadata), `7f9208f` (PR 07: bounded queues and retry classification), `664d953` (PR 07 fix: producer task cancellation).
- **Test Evidence**:
  - `Tests/TailscaleClientTests/StreamingTransportTests.swift` (8 tests)
  - `Tests/TailscaleClientTests/IPNBusStreamingTests.swift` (14 tests)
  - `Tests/TailscaleClientTests/IPNBusStreamingChallengerTests.swift` (110-cycle kernel introspection test)
  - `Tests/TailscaleClientTests/ConsumerValidation/NWXConsumerMigrationTests.swift:98` (`testContinuousIPNBusStreaming`)
- **Observed Metrics**: Peak memory strictly plateaus at $\le 16\text{MB}$ under burst traffic; zero orphaned tasks on consumer stream exit.

### Gate G4: Native Discovery Across Platforms & Flavors
- **Invariants**: Standalone `.pkg` app discovery reads `/Library/Tailscale/ipnport` symlink & `sameuserproof-<port>` token without TCC Apple Event prompts; App Store GUI Group Containers discovery requires explicit opt-in (`allowMacOSAppStoreDiscovery: true`); Linux uses systemd socket `/var/run/tailscale/tailscaled.sock`; asynchronous discovery API `discoverAsync()` executes off main actor; dynamic credential refresh: `.automatic` clients refresh port/token on `ECONNREFUSED` / HTTP 401 with single-flight deduplication; mutation replay safety prevents duplicate non-idempotent operations; tokens strictly redacted from diagnostics.
- **Commits**: `c8c50ec` (PR 08: native standalone discovery), `182d239` (PR 09: dynamic credential rediscovery), `0dfc37f` (PR 09 fix).
- **Test Evidence**:
