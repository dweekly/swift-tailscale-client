## 2. Evidence Status by Work Item

### Work Item W1 (Gate G1): Safe Writes
- **Implemented**: Lossless unmodeled JSON field preservation across `ServeConfig` hierarchies without 64-bit integer precision loss (`5e6ddc7`); `ServeConfigSnapshot` concurrency wrapper requiring non-empty ETag for `setServeConfig(_:matching:)` (`bbbe54a`).
- **Remediation Pending**: Binding `ServeConfigSnapshot` to its originating target (`targetIdentifier`) and enforcing target equality in `setServeConfig(_:matching:)` to prevent cross-target snapshot application.

### Work Item W2 (Gate G2): Transport Hardening
- **Implemented**: Unconditional 64 KiB head limit enforcement in `HTTPHeadBuffer` (`3be767b`); strict `Content-Length` and chunked transfer decoding completion checks; cooperative socket cancellation with `ManagedSocketFD` RAII ownership (`f7ead04`).
- **Remediation Pending**: Adding `maxLineBytes` to `NewlineFramer` to prevent unbounded memory growth on delimiterless streams; enforcing `maxBodyBytes` on unary response accumulation before EOF.

### Work Item W3 (Gate G3): Bounded Monitoring
- **Implemented**: `StreamingResponse` pre-flight metadata delivery (`be6bb42`); `IPNBusEvent` with `.lifecycle` and `.notification` separation; 256-event / 16 MB queue bounds with `.stateGap` overflow emission (`7f9208f`); deterministic producer task cleanup (`664d953`).
- **Remediation Pending**: Setting bounded buffering policy on transport `AsyncThrowingStream` instances; fixing `IPNBusBoundedQueue` overflow arithmetic so `gapEvent` (64 bytes) + incoming event cannot exceed the byte ceiling; replacing Python-only soak script with a harness measuring an actual child Swift process.

### Work Item W4 (Gate G4): Native Discovery
- **Status: PASSED**. Full verification of macOS standalone `.pkg` discovery (`/Library/Tailscale/ipnport`), opt-in App Store isolation, non-blocking `discoverAsync()`, cooperative probe cancellation, and single-flight restart rediscovery (`c8c50ec`, `182d239`, `0dfc37f`).

### Work Item W5 (Gate G5): Conformance & Fixtures
- **Implemented**: Automated fixture capture and pseudonymization tooling (`Scripts/capture-fixtures.py`); Go differential conformance harness (`Scripts/conformance-harness.go`); versioned fixture playback tests.
- **Remediation Pending**: Capturing real live daemon responses across matrix versions (manifests currently denote synthetic captures); importing official `tailscale.com` Go packages rather than self-contained structs in the conformance harness.

### Work Item W6 (Gate G6): Release Evidence
- **Implemented**: `all-required` GitHub Actions check aggregator; `Scripts/aggregate-release-evidence.py`; negative rehearsal suite (`Scripts/test-release-rehearsal.py`).
- **Remediation Pending**: Rejecting check-runs that lack explicit non-zero test execution counts (preventing unverified runs from defaulting to "passed"); requiring explicit individual matrix entries rather than regex pattern matching.

### Work Item W7 (Gate G7): API Baseline & Documentation
- **Implemented**: Removed deprecated `addProfile()`; raised DocC coverage to 100% authored member abstracts with `--warnings-as-errors`; 12 curated DocC guides.
- **Remediation Pending**: Establishing an immutable 1.0 API baseline file that guards the complete 1.0 public API surface against deletions; correcting toolchain documentation to Swift 6.1+ to match `Package.swift`.

### Work Item W8 (Gate G8): Consumer Validation & Governance
- **Implemented**: Non-`@testable` consumer simulation suites in `Tests/TailscaleClientTests/ConsumerValidation/` (`NWXConsumerMigrationTests.swift`, `FleetAgentConfigurationTests.swift`); canonical adoption brief (`Documentation/ADOPTION.md`).
- **Remediation Pending**: Conducting and documenting a genuine independent consumer deployment; conducting an external human technical review.

### Work Item W9 (Gate G9): Release Candidate & Soak
- **Implemented**: Soak verification script structure; accelerated test modes.
- **Remediation Pending**: Executing soak tests that launch, drive, and introspect a real Swift process; completing soak telemetry and evaluation period.
